        AI mode (optional)

        The offline engine is free and handles common Hinglish. For full-sentence translation, add your own Claude API key from console.anthropic.com. It is stored only on this device and is sent only to Anthropic's API.

        Use with WhatsApp

        1. Install SpeedX: open it in Chrome → menu ⋮ → Add to Home screen / Install app.
        2. Write here, send there: type in SpeedX and tap Send on WhatsApp — choose the chat and your proper-English message is already filled in.
        3. Fix a message from WhatsApp: select or long-press text → Share → SpeedX. It opens converted and ready to send back.
        4. Chatting casually? Switch Proper English OFF and SpeedX sends your text as-is.
